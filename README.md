# Folder_renamer

Утиліта для масового перейменування вкладених папок через GUI PowerShell.

## Чому «не працювало»
Було 2 типові причини:

1. **`PlaceholderText` у WinForms** в `rename_folders.ps1`.
   Ця властивість відсутня у класичному Windows PowerShell 5.1 / .NET Framework WinForms, тому скрипт падав під час запуску форми.
2. **Жорстко зашитий шлях `D:\rename_folders`** у `setup.bat`, `run_rename_folders.vbs` і `.reg`.
   Якщо диску `D:` немає або інший шлях інсталяції — пункт контекстного меню не запускав скрипт.

## Що змінено
- Замість `PlaceholderText` додані підписи (`Label`) для полів вводу — сумісно з Windows PowerShell 5.1.
- Інсталяція тепер у `%LOCALAPPDATA%\rename_folders`.
- `run_rename_folders.vbs` запускає `rename_folders.ps1` з **поточної папки VBS**, без hardcoded шляху.
- `setup.bat` генерує коректний `.reg` із фактичним шляхом інсталяції і імпортує його.

## Як встановити
1. Запусти `setup.bat`.
2. Клікни правою кнопкою на папці → **Rename Folders (PS)**.

## Як використати
1. Вибери кореневу папку (або залиш поточну).
2. Введи текст у полі **«Що замінити»** і **«На що замінити»**.
3. Натисни **«Перевірити»** для попереднього перегляду.
4. Натисни **«Виконати»** для застосування перейменувань.
